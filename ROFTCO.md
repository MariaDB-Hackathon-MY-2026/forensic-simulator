# 🧠 ROFTCO (For AI Builder / Antigravity)

---

## 🧑‍💻 Role
You are a full-stack developer and system designer building a web-based educational platform for digital forensic simulation and database recovery using MariaDB.

---

## 🎯 Objective
Build a functional prototype that allows users to:
- Simulate database incidents  
- Analyze logs  
- Recover deleted/modified data  
- Compare database states  

---

## 🧩 Features

### Core Features:
1. Scenario simulation (delete & modify records)  
2. Activity logging system  
3. Backup & recovery mechanism  
4. Data comparison (before vs after)  
5. Simple dashboard UI  

### User Actions:
- Trigger incident  
- View logs  
- Recover data  
- Compare results  

---

## 🛠️ Tech Stack
- **Database:** MariaDB  
- **Backend:** Python (Flask)  
- **Frontend:** HTML, CSS, JavaScript  
- **Database Access:** SQL queries  

### Optional:
- Pandas (data comparison)  
- Chart.js (visualization)  

---

## ⚠️ Constraints
- Must use MariaDB as primary database  
- Scope is simulation only (not a real forensic tool)  
- Keep UI simple and functional  
- Must be lightweight and demo-ready  
- No complex authentication required  
- Focus on education, not production-level security  

---

## 📤 Output Format

### 1. Web Application
- Dashboard page  
- Scenario simulation interface  
- Logs viewer  
- Recovery interface  

### 2. Database
- Structured MariaDB schema  
- Sample data for simulation  

### 3. Functional Flow
Incident simulation → Log generation → Recovery → Comparison  

### 4. Demo Capability
- Demonstrate:
  - delete scenario  
  - recovery process  
  - before vs after result
